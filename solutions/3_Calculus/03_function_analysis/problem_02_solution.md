# Problem 2. A Parabola from the Perspective of the Derivative

## Problem

For $f(x)=x^2-4x+1$, find the minimum using the derivative and compare with the vertex form.

## Solution

Let $f(x)=x^2-4x+1$. A minimum occurs where $f'$ changes from negative to positive.

### Step 1 - Find the critical point

The critical-point condition $f'(x)=0$ identifies possible extrema because at an interior extremum the tangent is horizontal. The derivative sign test determines which kind occurs.

$$
f'(x)=2x-4=2(x-2).
$$

Thus $x=2$ is the only critical point. It is a minimum because $f'(x)<0$ for $x<2$ and $f'(x)>0$ for $x>2$.

### Step 2 - Compute the value

$$
f(2)=4-8+1=-3.
$$

### Vertex-form verification

Completing the square,

$$
f(x)=x^2-4x+1=(x-2)^2-3.
$$

The square is nonnegative and is smallest at $x=2$, giving value $-3$. This independently confirms the derivative result.

## Final Answer

The minimum is $-3$ at $x=2$, at $(2,-3)$.
