# Problem 6. A Logarithmic Function

## Problem

Analyze $f(x)=\ln x-x+1$: domain, zero, and monotonicity.

## Solution

Let $f(x)=\ln x-x+1$.

### Domain

The logarithm requires $x>0$, so

$$
D_f=(0,\infty).
$$

### Derivative

$$
f'(x)=1/x-1=(1-x)/x.
$$

On $(0,\infty)$, the sign is that of $1-x$. Thus $f$ is increasing on $(0,1)$ and decreasing on $(1,\infty)$.

### Zero and check

$$
f(1)=\ln1-1+1=0.
$$

The derivative changes positive to negative at $1$, so $(1,0)$ is a global maximum. No other zero is possible because the function increases to this maximum and then decreases, never becoming zero again.

## Final Answer

Domain $(0,\infty)$; unique zero $x=1$; increasing on $(0,1)$; decreasing on $(1,\infty)$; maximum $(1,0)$.
